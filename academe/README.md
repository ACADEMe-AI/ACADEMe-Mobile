# ACADEMe

The ACADEMe app, rebuilt from scratch: Flutter client, Go API, PostgreSQL.
Play Store package `com.academe.flutter`. Never call competitor apps'
services or ship their assets.

Rules: `AGENTS.md` (app) and `server/AGENTS.md` (API).

Run:
1. Server — see `server/AGENTS.md` → "Running locally".
2. `flutter run -d emulator-5554` from this directory (Pixel 10 only).
