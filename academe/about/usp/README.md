# ACADEMe unique selling propositions

The current USP decisions are recorded in `../../tasks/roadmap.md` under
`USPs`. This directory is the durable index for positioning material and future
USP evidence.

## Current positioning

ACADEMe is a syllabus-aware study app for Indian school students that combines
Indian-language learning, swipe lessons, a step-by-step AI tutor, homework
scanning, board-style answer checking, revision, and exam planning.

## Evidence rule

A USP may be marked as built only when the repository, a test, or a shipped
product path demonstrates it. Planned positioning must not be presented as a
current capability.
