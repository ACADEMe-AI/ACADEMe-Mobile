Subjects and filters

These designs build on the app as it is today. Each section starts with a real Pixel 10 screenshot (grey frame, Today), followed by proposals (New) made from the same pieces: the Courses / Folders toggle, the amber pills, the purple Continue keycap, the chapter rows with green progress rings, and the setup sheet.

1 · Home subjects

Today the tiles are plain labels for every subject on the board. In both proposals Home shows only the student's subjects, each one opens Study → Courses with that subject selected, and there's an Edit link. A keeps the current tinted tiles and adds progress. C turns them into rows with the next lesson.

2 · Pick subjects in setup

A fifth step in the existing setup sheet, in the same style (SET UP · n/5, +25 XP, Later, a big question and a primary button). Class 6–10 comes with everything selected. Class 11–12 first picks a stream on swipe cards, just like the language step.

3 · Study → Courses, with filters

Same page as today, with three changes. The subject pills show only the student's subjects, so they fit in one row. The All / In progress / Done row gets a Filters key (the tune icon) at the end, which opens a sheet. Active filters show as removable chips above the list.

4 · Study → Folders

The Folders tab stays as it is. Adding chapters to a folder now offers only the student's subjects, and the same Filters pill works there too.

5 · Change later

Me → Class and board gets Stream and Subjects rows. They open the same picker as setup, as a sheet.

6 · What gets built

Server

  • A subjects list on the profile (migration 0023). PATCH /me/profile checks each code against the class and board.
  • GET /catalog/streams returns the Class 11–12 streams with their main and optional subjects.
  • The catalogue adds per-subject counts, lesson minutes and whether each chapter has revision due, which the filters need. The change is additive only.

App

  • A fifth setup step and a Subjects row in Me → Class and board.
  • Home subjects: either A (tiles with progress) or C (rows), both tappable.
  • Courses: pills for the student's subjects only, a Filters pill and sheet (board exam only, ready to study, revision due, sort by marks or recent), and active-filter chips.
  • Add chapters uses the same subject list. Students with no picks saved see every subject plus a one-time "Pick your subjects" card.
